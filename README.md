## О проекте и комплексе `CDQuad`

При регистрации длительных серий в цейтраферной флуоресцентной микроскопии живых клеток операторы используют аппаратный биннинг пикселей (`4×4`, `6×6`) для снижения фототоксичности, тогда как диагностическая морфометрия выполняется на кадрах полного разрешения или адаптивных триангуляциях Делоне. Классические комбинаторные графовые нейронные сети конвекции-диффузии (включая локальный 1-шаговый вентиль модели `AdaCDE`) при измельчении пространственного шага сетки вырождаются со скоростью `Θ(h²_G) → 0`, выключая направленный перенос на высоком разрешении.

Разработанный открытый программно-алгоритмический комплекс **`CDQuad`** (*Continuum-Consistent Convection-Diffusion Quadrature*) решает эту проблему за счёт:

1. **Континуально-согласованного оператора переноса:** кусочно-линейная конечно-элементная жёсткость анизотропного тензора диффузии `K(x)` + строго консервативные противопоточные (`upwind`) потоки на барицентрических дуальных ячейках Дональда + нелокальный гауссов вентиль фиксированного физического радиуса `r₀ > 0`.
2. **Равномерной устойчивости по числу Пекле:** бездивергентное поле скорости полностью выведено из показателя экспоненты Гронуолла, обеспечивая линейный масштаб ошибки по `Pe ∈ [0, 100]` (`R² = 0,9998`) и затухание межуровневого расхождения на длинных горизонтах времени.
3. **Быстровычислимой конформной сертификации без эталонного решателя:** эллиптический двойственный дефект `δ̂₋₁(G)` на словаре из 15 косинусных мод Неймана в норме `H⁻¹_G` и `split-conformal` калибровка (`4,2 мс` при `N = 3025`) с аналитическим переносом границ через константы Липшица на сглаженную площадь `M₀` и барицентр `M₁`.

## Структура репозитория

```text
BSU-FIT/
├── index.html                        # Интерактивный веб-сайт проекта (GitHub Pages)
├── requirements.txt                  # Зависимости открытого стека Python / SciPy
├── LICENSE                           # Открытая лицензия MIT
├── src/                              # Модульное ядро программного комплекса CDQuad
│   ├── meshes.py                     # Решётки, триангуляции Делоне, ячейки Дональда, SLIC RAG
│   ├── operators.py                  # Матрицы P1-жёсткости K(x), upwind-потоки и решатели CN / IMEX
│   ├── certificate.py                # Двойственный дефект в H^-1_G (15 мод Неймана) и split CP
│   ├── descriptors.py                # Глобально липшицевы морфометрические дескрипторы M0, M1, V
│   ├── exp1_sanity_and_convergence.py
│   ├── exp2_certificate_and_shift.py
│   └── exp3_applied_morphometry.py
├── data/
│   └── NPCsingleNucleus.tif          # Цейтраферная флуоресцентная микроскопия живого ядра (15 кадров)
├── results/
│   ├── exp1_results.json             # Протоколы сходимости O(h^2), масштаба Пекле и коллапса AdaCDE
│   ├── exp2_results.json             # Протоколы калибровки сертификата на 160 сетках и стресс-тестов OOD
│   ├── exp3_results.json             # Протоколы синтетической и реальной живой микроскопии
│   └── figures/                      # Итоговые графики экспериментов
└── referats/oit/
    ├── ДовгийАС_Реферат.pdf          # Итоговый реферат по ОИТ (33 страницы)
    ├── Certified_Cross-Scale_Graph_Morphometry.pdf # Презентация к защите (15 слайдов)
    ├── assets/                       # Веб-иллюстрации, слайды и сканируемый QR-код
    └── latex/                        # Полный исходный проект XeLaTeX (main.tex, главы, фигуры)
```

## Воспроизведение всех расчётов и сборка реферата

```bash
# 1. Установка зависимостей
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 2. Полный прогон вычислительных экспериментов (фиксированное зерно 20261122)
python -m src.exp1_sanity_and_convergence
python -m src.exp2_certificate_and_shift
python -m src.exp3_applied_morphometry

# 3. Двухпроходная сборка реферата в XeLaTeX
cd referats/oit/latex
xelatex -interaction=nonstopmode main.tex
xelatex -interaction=nonstopmode main.tex
```
